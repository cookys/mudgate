2. **Proxy freeform errors** → `proxy_error` + opaque detail; not status identity.

4. **`localStorage` try/catch** + **allowlist** `zh-Hant|en`.
5. **Boot `html lang` before paint** (`main.tsx` / tiny inline); terminal region isolate `lang` so world text ≠ UI locale.
6. **I2 must not merge half-done** — status structured path gated with shell copy (or single “i18n v1 done” gate including I3).

8. **ConnectGate switcher above fold**; drawer shared same state; topbar compact optional desktop-only.
