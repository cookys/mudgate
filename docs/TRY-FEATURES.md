# 功能試玩最短路徑（LAN）

> 給人類 2～5 分鐘點完。  
> 預設：本機已起 **web + proxy**，你開  
> **http://192.168.101.20:5173/**  
> （同網段手機／另一台電腦也可）

---

## 0. 進得去、連得上

| 步驟 | 點哪／做什麼 | 預期 |
|------|----------------|------|
| 1 | 瀏覽器開 `http://192.168.101.20:5173/` | 出現 mudgate 連線畫面 |
| 2 | 信任模式選 **本機／LAN（T0）** | 不必填遠端 token |
| 3 | 選 profile（例如 RW）→ **連線** | 狀態變連線；終端有字 |
| 4 | 若連不上 | 確認與 192.168.101.20 同網段；本機 `curl http://192.168.101.20:17788/health` 應 `ok` |

---

## 1. 側邊導航：附近 / 足跡 / 城圖

| 步驟 | 點哪 | 預期 |
|------|------|------|
| 1 | 頂列或側欄 **地圖／導航** 圖示（開側邊） | 右側出現導航面板 |
| 2 | 分頁 **附近** | 有房名（走幾步後）＋九向方向鍵 |
| 3 | 點方向（東／北…） | 指令送出；足跡會變 |
| 4 | 分頁 **足跡** | 簡易圖／路徑節點（session 推測，不是官方城圖） |
| 5 | 分頁 **城圖** | Companion：快照／釘住／凍結等（下面 2） |

**白話：** 附近＝現在這間怎麼走；足跡＝這次連線走過哪；城圖＝終端地圖的記憶本。

---

## 2. 城圖副駕（Companion C0）

在側邊 **城圖** 分頁：

| 步驟 | 點哪 | 預期 |
|------|------|------|
| 1 | 遊戲裡開地圖（RW 通常 `map` 或你們站的指令） | 終端出現大片地圖畫面 |
| 2 | 等 1 秒 或開 **自動擷取** | 側邊可能出現快照；徽章 **「自動擷取 · 推測」**（不是「官方」） |
| 3 | **釘住終端** | 立刻存目前終端畫面；徽章 **「終端快照」** |
| 4 | **凍結** | 這張不被新自動抓蓋掉 |
| 5 | **即時** | 再跟「最新抓到的」走 |
| 6 | 在 canvas 上點一格 → 輸入註記 → 存 | 出現 pin；列表可編輯／刪 |
| 7 | **1× / 2×**、拖曳 | 縮放、平移 |
| 8 | **清除本檔資料** → 確認 | 此 profile 的幀／釘／旅程記憶清掉 |

**空狀態：** 還沒抓過會提示去開 map 或釘住。

---

## 3. 旅程錄放（C1）

仍在 **城圖** 分頁下方 **旅程**：

| 步驟 | 點哪 | 預期 |
|------|------|------|
| 1 | 名稱可填（如「回銀行」）→ **錄** | 開始錄指令 |
| 2 | 用方向鍵或指令列走幾步 | 每步記一筆（密碼模式不會錄） |
| 3 | **停錄** | 列表出現旅程與步數 |
| 4 | **播** | 進入重播，顯示 step 1… |
| 5 | **下一步** | 送出該步指令；**等 mud 回應** 才進下一步 |
| 6 | 故意撞牆／走死路 | 應 **中斷**（移動失敗）；或房名完全沒變也會中斷 |
| 7 | **出** | 匯出 JSON 到剪貼簿；**入** 可貼回 |

**白話：** 不是自動跑完全程，是「備忘路線＋你按一下走一步」。

---

## 4. 搜尋、指紋、拼接（C1）

城圖上方工具列：

| 步驟 | 點哪 | 預期 |
|------|------|------|
| 1 | 搜尋框輸入 pin 裡寫過的字（如「銀行」）→ Enter／搜尋 | 列表命中，點可跳該幀 |
| 2 | **指紋掛回** | 若與已存幀很像會列候選；完全相同才可能自動切 |
| 3 | 勾 **拼接** | 出現實驗標＋下方 **文字全景**（`stitch-panorama`） |
| 4 | 開 map、走 n/s/e/w 幾步（最好有自動擷取） | tile 數增加；全景裡應多出拼在一起的字元 |
| 5 | **清空拼接** | 全景清空 |

**白話：** 拼接＝實驗性「把幾張截圖拼成一塊記憶」，別當正確導航儀。

## 5. 站方模式（一般玩家可略過）

給**泥巴站長**，不是日常玩家必試：

```bash
# 空 allowlist 應直接失敗（防誤開）
MUDGATE_PROXY_MODE=remote-prod MUDGATE_SITE_MODE=1 \
  MUDGATE_AUTH_TOKEN=x MUDGATE_ORIGIN_ALLOWLIST=https://x.example \
  npx tsx apps/proxy/src/cli.ts
# → 要求 MUDGATE_ALLOWLIST
```

操作手冊：`docs/deploy/SITE-OPERATOR.md`。

## 6. 出問題時快速對照

| 現象 | 先查 |
|------|------|
| 網頁開不了 | `curl -s http://192.168.101.20:5173/` 是否 200 |
| 連線失敗 | `curl -s http://192.168.101.20:17788/health` 是否 ok；信任模式是否 T0 |
| 城圖一直空 | 終端是否真的開了 map；試 **釘住終端**；自動擷取是否勾著 |
| 旅程不停步／不中斷 | 看是否出現「你不能…」類失敗句；或房名是否完全沒變 |
| 拼接沒畫面 | 是否勾了拼接、是否至少抓到 2～3 幀 |

---

## 一條「最少點完」清單（約 3 分鐘）

1. LAN 開頁 → T0 連線  
2. 開側邊 → **附近** 走兩步 → **足跡** 看一眼  
3. 遊戲 `map` → **城圖** → 釘住或等自動抓 → 點一格寫 pin  
4. **錄** 走三步 → **停錄** → **播** → **下一步**  
5. （可選）勾 **拼接** 再 map 走幾步看全景字  

做完就等於把這輪「導航副駕」主路徑摸過了。
