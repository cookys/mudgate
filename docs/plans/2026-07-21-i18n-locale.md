# Plan — UI locale switch (i18n) for mudgate shell

> **Status**: **SHIP baseline** (I1–I3 on develop via feat/i18n-fonts) — residual: full tagline packs polish, drawer font strings i18n  


> **Owner**: cookys  
> **Branch**: `feat/ui-redesign` (co-ship) / optional `feat/i18n-locale`  
> **Why**: Shell 字串中英混用且 hardcode；`html lang` 與實際 chrome 不一致；正體／簡體／英文使用者都需要可切換 UI。  
> **Goal**: **語系可切換、可持久化、可擴充**；**不碰** MUD 協議 / 終端熱路徑；世界內文永遠以伺服器 charset 為準。

**Hetero review**: `docs/reviews/2026-07-21-i18n-hetero.md`  
**Linked**: UI redesign · `docs/design/ui-spec.md` · **terminal fonts** `docs/design/terminal-fonts.md`

## 0. Research notes (industry)

| Pattern | Takeaway for mudgate |
|---------|---------------------|
| **UI chrome ≠ world content** | i18n 只翻譯 **client shell**。**不翻譯** MUD 輸出、腳本關鍵字、alias 本體。 |
| **Lightweight dictionary > heavy i18next** (small SPA) | 字串量 < ~200 keys → `messages/{locale}.ts` + `t(key)`；v1 不做 ICU/RTL。 |
| **Locale persistence** | `localStorage`（try/catch）+ 初次 `navigator.language`；顯式選擇優先。 |
| **`document.documentElement.lang`** | 切換時寫 allowlisted tag；**終端容器**另設 `lang` 隔離（見 §2.5）。 |
| **Status is data, not copy** | Socket/UI state 只存 **status code + params**；顯示層才 `t()`。 |
| **Mudlet/zMUD precedent** | UI language ⊥ game encoding（encoding 屬 profile）。 |

### 0.1 Scope boundary (hard)

| In scope (shell) | Out of scope |
|------------------|--------------|
| ConnectGate、PlayShell、drawer、ConfirmModal、command bar、thumb labels、a11y | MUD 串流、腳本 pack 內容 |
| `html lang`（chrome）、terminal host `lang` 隔離 | 自動翻譯 server 輸出 |
| 結構化 `StatusEvent` + 顯示翻譯 | Proxy 錯誤多語（可維持 EN detail） |
| `zh-TW` + `zh-CN` + `en` | Crowdin / RTL / 其他語系 |

### 1.1 站台設定 vs 偵測（§8.1 細則）

```
resolveLocale():
  if localStorage.mudgate.locale ∈ allowlist → use it   // 使用者明確選過
  else if SITE_DEFAULT ∈ allowlist → use SITE_DEFAULT // 站台營運設定
  else detect(navigator.language)                     // 瀏覽器
  else zh-TW                                          // 最後後備（產品主場正體）
```

- **SITE_DEFAULT** 來源（實作擇一或兼有，優先序高→低）：  
  1. `window.__MUDGATE_SITE__?.defaultLocale`（hosted 注入）  
  2. `import.meta.env.VITE_DEFAULT_LOCALE`  
  3. 無  
- 使用者在 UI 選過語系後 **永遠以 localStorage 為準**，直到清資料。

## 2. Design thesis

> **「殼說人話，世界說 MUD 話」** — UI locale 只服務操作者；bytes → Big5/VT **永不** 經 i18n。

### 2.1 Architecture

```
MudSocket ──► StatusEvent { code, params? } ──► tab.status (typed)
                                      │
                                      ▼
                              statusCopy(event) → MessageKey + vars
                                      │
                                      ▼
LocaleProvider ── t(key, vars) ──► StatusPill label + tone(code)
                                      │
ConnectGate / Modal / Drawer / CommandBar ── t(...)
                                      │
Terminal stage ── lang="und" 或 profile charset hint（不跟 UI locale）
```

**Import fence**: `MudSocket` / `TerminalHost` / `packages/*` **不得** `import` `i18n/*`。

### 2.2 File-structure map

| Path | Role |
|------|------|
| `apps/web/src/i18n/types.ts` | `Locale`, **`MessageKey` required union**, `StatusEvent` |
| `apps/web/src/i18n/messages/zh-TW.ts` | 正體 shell 文案 |
| `apps/web/src/i18n/messages/zh-CN.ts` | 簡體 shell 文案 |
| `apps/web/src/i18n/messages/en.ts` | English shell |
| `apps/web/src/i18n/taglines/*.ts` | EN Ass 包 + 中文玩笑包 |
| `apps/web/src/i18n/t.ts` | `t(locale, key, vars?)`；missing key → en fallback → key string |
| `apps/web/src/i18n/localeStore.ts` | detect / load / save（try/catch + allowlist） |
| `apps/web/src/i18n/LocaleContext.tsx` | Provider + `useT()` / `useLocale()` |
| `apps/web/src/i18n/statusCopy.ts` | `StatusEvent` → `{ key, vars }` + `tone(code)` |
| `apps/web/src/components/LocaleSwitch.tsx` | `繁中 \| English` / compact |
| `apps/web/src/lib/mudSocket.ts` | emit **StatusEvent only**（breaking clean cut） |
| `apps/web/src/components/StatusPill.tsx` | tone from **code**，label from `t()` |
| tests | key parity；detect；statusCopy matrix；storage garbage |

### 2.3 StatusEvent (mandatory — Architect/Skeptic kill-shot)

```ts
type StatusCode =
  | "idle"
  | "connecting"
  | "handshaking"
  | "connected"
  | "disconnected"
  | "reconnect_wait"   // params: { seconds, attempt, max }
  | "max_retries"
  | "proxy_error"      // params: { detail?: string }  // opaque, not identity
  | "bad_frame"
  | "error";           // generic

type StatusEvent = { code: StatusCode; params?: Record<string, string | number> };
```

- Equality / dedupe：`code` + 序列化 `params`，**不是** 顯示字串。  
- Proxy `{ type: "error", message }` → `proxy_error` + `detail` 截斷消毒。  
- **刪除** plan 舊文「regex 過渡」路徑。

### 2.4 Message keys (inventory v1 — all required for “done”)

含但不限於：ConnectGate 全表單、Accent 標籤、Locale 標籤、Connect CTA、export/import、topbar map/settings、Send、placeholder、session idle、tab close modal（連線中/閒置）、drawer 全操作、status.* 全 codes、max retries 提示。

Interpolation：僅 `{name}` / `{n}` / `{a}` / `{max}` 字面替換。

### 2.5 `lang` isolation (Skeptic kill-shot)

| Node | `lang` |
|------|--------|
| `<html>` | UI locale（`zh-TW` / `zh-CN` / `en`） |
| Terminal stage wrapper | `lang="und"`（或未來 profile charset）— **不**把 MUD 世界假稱為 UI 語系 |

避免 AT/瀏覽器整頁當英文去「翻譯」Big5 世界。

### 2.6 Boot order (Ops)

1. `main.tsx` 最前置：`loadLocale()` → `document.documentElement.lang = …`  
2. （可選 I4）`index.html` 3 行 inline 讀 `mudgate.locale` 減 FOUC  
3. 再 `createRoot`

### 8.1 Q5 白話：`StatusEvent` 是什麼？要改什麼？

**現在的問題**  
連線狀態（連線中、重連倒數、錯誤）是 **一整句英文** 從 WebSocket 層丟進 React，例如：

- `"connecting…"`
- `"reconnect in 4s… (2/12)"`
- `"disconnected (max retries — use Connect again)"`

UI 若要顯示中文，只能對英文句子做 **髒 regex**。一切換語系或改一句英文 copy，狀態燈顏色、翻譯就爆。Hetero review 因此 **BLOCK**。

**要改成什麼**  
`MudSocket` **不要再吐「給人看的句子」**，只吐 **機器狀態碼 + 參數**：

```ts
// 以前
onStatus("reconnect in 4s… (2/12)")

// 以後
onStatus({ code: "reconnect_wait", params: { seconds: 4, attempt: 2, max: 12 } })
```

然後 **只有 UI** 用目前語系翻譯：

- en → `reconnect in 4s… (2/12)`  
- zh-TW → `4 秒後重連…（2/12）`  
- zh-CN → `4 秒后重连…（2/12）`  

狀態燈（綠/黃/紅）也只看 `code`，不看句子裡有沒有 `"recon"`。

**會動到的檔案（小、可控）**  
`mudSocket.ts`、`TerminalHost.tsx`、`App.tsx` 的 `tab.status` 型別、`StatusPill.tsx`。  
**不會**動 proxy 協議、Big5、VT、MUD 世界內容。

**為什麼一定要做**  
沒有這步就做不好「正/简/EN 切換」——重連那幾秒使用者最焦慮，卻可能一直顯示英文或燈號錯亂。

## 9. Success criteria

1. ≤2 次點擊完成語系切換，shell 全文跟隨（tagline 走對應語言包）  
2. 重新整理後 locale 維持；站台預設在「未選過」時生效  
3. `<html lang>` ∈ `zh-TW`\|`zh-CN`\|`en`；終端區 `lang` 隔離  
4. Status 色點 / 文案三語正確  
5. Big5 / VT / proxy 零回歸；無 i18next  
6. （並行）終端字體可切、可調字級/字寬；預設 dual-width mono（見 terminal-fonts.md）
